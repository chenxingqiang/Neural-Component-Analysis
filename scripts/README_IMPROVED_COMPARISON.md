# SECOM故障检测方法对比分析 - 改进版

## 概述

这是对原始SECOM故障检测对比框架的重大改进版本，解决了之前分析中发现的关键问题，并添加了多项新功能。

## 主要改进

### 1. 解决SPE极值问题
- **问题**: 原始SPE值存在极值（最大值是99%分位数的17.5倍），影响可视化和分析
- **解决方案**: 
  - 使用对数变换处理极值
  - 实现分位数截断（99.5%）
  - 添加极值标注和说明

### 2. 增强的可视化分析
- **3x3子图布局**: 包含检测图、性能对比、ROC曲线、分布分析等
- **论文质量图像**: 300 DPI高分辨率，适合学术发表
- **极值处理**: 智能处理极值，保持可视化清晰度
- **性能指标显示**: 直接在图上显示FAR、MDR、AUC等关键指标

### 3. 全面的性能分析
- **统计显著性检验**: T-test和Mann-Whitney U检验
- **ROC/PR曲线分析**: 自动计算AUC指标
- **分离度分析**: 正常和故障样本的分离能力评估
- **极值比例分析**: 量化极值问题的严重程度

### 4. 智能对比表格
- **中文界面**: 更直观的中文显示
- **综合指标**: 误报率、漏报率、检测延迟、ROC AUC、分离度、极值比
- **性能分级**: A/B/C/D级自动分级
- **改进建议**: 基于结果的具体改进建议

### 5. 集成优化分析
- **自动调用优化分析**: 对最佳方法自动运行详细分析
- **阈值敏感性分析**: 自动寻找最佳阈值
- **综合报告生成**: 自动生成分析总结

## 使用方法

### 基础运行
```bash
# 运行基础对比（PCA + Enhanced Transformer）
python scripts/secom_comparison_detection.py

# 包含Improved Transformer（较慢）
python scripts/secom_comparison_detection.py --include_improved

# 包含Transformer-Enhanced Two-Stage检测器
python scripts/secom_comparison_detection.py --include_transformer

# 完整分析（所有方法）
python scripts/secom_comparison_detection.py --include_improved --include_transformer
```

### 测试功能
```bash
# 运行测试验证改进功能
python scripts/test_improved_comparison.py
```

## 性能指标说明

### 主要指标
- **误报率 (FAR)**: 正常样本被误判为故障的比例
- **漏报率 (MDR)**: 故障样本未被检测的比例  
- **检测延迟**: 故障发生后多少样本才检测到
- **ROC AUC**: 接收者操作特征曲线下面积
- **分离度**: 故障样本与正常样本SPE均值比值
- **极值比**: 最大SPE值与99%分位数的比值

### 性能分级
- **A级 (优秀)**: FAR < 5% 且 MDR < 5%
- **B级 (良好)**: FAR < 10% 且 MDR < 10%
- **C级 (可接受)**: FAR < 20% 且 MDR < 20%
- **D级 (需改进)**: 其他情况

## 技术特性

### 极值处理策略
1. **对数变换**: `log10(SPE + 1)` 压缩极值范围
2. **分位数截断**: 截断到99.5%分位数用于可视化
3. **智能标注**: 自动标注极值信息
4. **分段显示**: 必要时使用分段坐标轴

### 统计分析
1. **显著性检验**: 自动进行方法间统计比较
2. **置信区间**: 基于KDE的控制限计算
3. **鲁棒性评估**: 多种统计指标综合评估

### 可视化优化
1. **学术风格**: 符合期刊发表标准
2. **高分辨率**: 300 DPI适合印刷
3. **色彩优化**: 色盲友好的配色方案
4. **布局优化**: 信息密度与可读性平衡

## 故障排除

### 常见问题
1. **内存不足**: 减少方法数量或使用更小的数据集
2. **运行时间长**: 使用`--skip_improved`跳过耗时模型
3. **图像生成失败**: 检查matplotlib后端设置
4. **导入错误**: 确保所有依赖包已安装

### 依赖要求
```
numpy >= 1.19.0
matplotlib >= 3.3.0
scikit-learn >= 0.24.0
scipy >= 1.6.0
seaborn >= 0.11.0
torch >= 1.8.0
```
